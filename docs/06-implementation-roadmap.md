# 90-Day Implementation Roadmap

## Days 0–30: Discovery & Alignment
- Identify existing risk acceptance processes
- Map approval authorities
- Align to risk appetite
- Confirm system of record
- Draft unified intake workflow

Deliverables:
- Current-state gap analysis
- Executive alignment session
- Tier threshold confirmation

---

## Days 31–60: Build & Pilot
- Configure intake workflow
- Define SLAs
- Deploy expiration tracking
- Pilot in one business unit

Deliverables:
- Operational acceptance form live
- Routing matrix finalized
- Pilot performance metrics

---

## Days 61–90: Enterprise Rollout
- Roll out unified process enterprise-wide
- Train stakeholders
- Implement executive dashboard
- Formalize renewal cadence

Deliverables:
- Centralized acceptance register
- Executive reporting view
- Governance publication
